Definition & reference

DCI = (sum of terminal orders + number of tips) × total dendritic length / number of primary dendrites. Orders count dendritic branch points from the soma (unbranched stem = 0), not SWC sampling points. Length in µm; radius, rigid rotation and bifurcation tilt do not change DCI. No dendrites gives 0 by convention.

Rule precedence

Defaults → layer → population → individual cell. Overall writes the individual feature settings. Editing one detail resets the Overall command to zero without changing the other values. Legacy df_percent recipes remain supported; explicit feature values take precedence.

A portable reconstruction package

Extract the ZIP and run bash reconstruct.sh in a matching BSB 8 environment. Morphologies are already transformed; the Designer does not need to be running or installed.

SCOPE OF VERSION 0.0.1

Development & limitations

What the current Designer changes, what it assumes, and what remains to be implemented.

Current scope

  • Native Windows editor: morphology previews, configuration, saved profiles and export work without Ubuntu, WSL or an installed Python. Exact network placement, reconstruction and simulation are separate BSB tasks. The live network preview is an estimate based on bundled canonical coordinates.
  • Uniform changes within each population. All cells of the same population receive the same changes in this editor. Cell-specific variability and sigma are not exposed.
  • Transformation of existing morphology. Existing SWC geometry can be scaled, rigidly rotated, or modified by rotating daughter subtrees at dendritic bifurcations. Bifurcation tilt preserves branch lengths and topology but changes spatial shape and may change branch opening angles. No dendritic growth, data-driven morphology inference, new branches, spines or compartments are generated.
  • Point-neuron electrophysiology. Electrical controls change the NEST EGLIF multireceptor spiking model. It has no multicompartment dendritic cable model or spatially resolved channel distributions.
  • Geometry and electricity are independent. A larger soma or longer dendrite does not automatically change capacitance, conductances or membrane time constants.
  • Cortical subset, currently mouse. The selected configuration excludes deep cerebellar nuclei (DCN, including DCN-P), inferior olive (IO), unipolar brush cells (UBC), other subcortical populations and downstream targets. Mossy fibers and glomeruli are input/relay representations, not detailed biological cell morphologies. This describes the Designer configuration, not every model available upstream.
  • No zebrin II positive/negative distinction. Purkinje cells are represented as one population. Zebrin II (aldolase C) positive and negative subpopulations, parasagittal stripes and subtype-specific morphology, physiology or connectivity are not implemented.
  • In vitro only for this model. The installed multireceptor preset supports in vitro. An awake preset for a different model is not substituted automatically.
  • Preview and reconstruction differ. Live cell counts use linear proportions. Exact placements and connectivity depend on reconstruction, geometry and the native BSB rules; new connection rules are not inferred.
  • Exploratory bifurcation tilt. Referenced to Mavroudis et al. (2017), not fitted to their human measurements. The explicit parent-facing angle convention is documented in the control and export report. Binary dendritic forks only; duplicate SWC junction samples are skipped when measuring direction, not deleted. Daughter angles are clipped to 1–179° and clipping is reported. No collision avoidance or layer-boundary clipping. Connectivity must be rebuilt from changed geometries; electrical kinetics are unchanged.
  • Spatial sampling needs convergence checks. Reading the selected connectivity configuration… voxels_pre/post approximate the number of subdivisions of each morphology's bounding box, not a fixed resolution in µm. Deformation therefore changes the physical voxel sizes. BSB 8 voxelizes branch sample points; this step does not interpolate the segments between them or use neurite radii to set voxel occupancy. Thin or sparsely sampled branches may affect contacts. A radius-only change does not directly change occupancy in this strategy.
  • Chunk size is a different parameter. Chunks partition space for placement/storage/task allocation; they are not the morphology sampling interval. No automatic resampling or resolution adjustment is applied by this Designer.
  • Exploratory profiles. Pathology presets are modelling hypotheses. Valid YAML does not establish biological validity or predict firing rates; simulation and comparison with data are separate steps. Large deformations may violate placement constraints.

Development directions

Spatial-resolution validation
Compare connectivity, convergence and divergence across voxel counts and SWC sampling densities, before choosing any deformation-dependent resolution policy. Native connectivity settings are currently preserved.

Cell-specific heterogeneity
Expose and validate distributions and individual transformations in the editor.

NEURON support
Add a separate multicompartment workflow, including morphology discretization, mechanisms and parameter mapping.

Human option
Requires human morphology, layer and population data, connectivity and electrical calibration; changing the species label alone is insufficient.

In-vivo multireceptor condition
Requires a compatible baseline and validation before the condition can be enabled.

Planned capabilities are disabled in the interface; none of them is applied silently.
